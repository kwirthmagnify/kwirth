# @kwirthmagnify/kwirth-common-ai

Shared AI/LLM types and utilities for [Kwirth](https://kwirthmagnify.dev) AI plugins.

## What is this?

This package contains the TypeScript interfaces and utilities for working with LLM providers and models in Kwirth: `ILlm`, `IProvider`, `IModel`, `buildModel`, `loadModels`, and related types.

## Installation

```bash
npm install @kwirthmagnify/kwirth-common-ai
```
