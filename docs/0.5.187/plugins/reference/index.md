# Plugin reference

Detailed configuration and usage reference for each available Kwirth plugin.

| Plugin | Description |
|---|---|
| [Log](log) | Real-time aggregated log streams with filtering, sorting, and timestamp support |
| [Alert](alert) | Regex and metrics-based alerting with sender integration |
| [Censor](censor) | LLM-powered log analysis and sensitive pattern detection |
| [Ops](ops) | Interactive shell, pod restart, namespace operations |
| [Fileman](fileman) | Visual file manager for container filesystems |
| [Trivy](trivy) | Vulnerability, SBOM, config audit, and secret scanning via Trivy Operator |
| [Pinocchio](pinocchio) | AI-powered artifact validation and business-data analysis |
| [Topology](topology) | Interactive 3D cluster visualization and management |
| [Echo](echo) | Reference implementation for plugin developers |
| [News](news) | RSS feed streaming — reference for external-data plugins |
