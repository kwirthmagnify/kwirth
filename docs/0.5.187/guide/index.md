# User & Admin Guide

Welcome to the **Kwirth User & Admin Guide** — a self-contained, task-oriented manual that walks you through **how to use** and **how to configure** Kwirth, from your first login to running advanced observability workflows and administering the whole platform.

> This guide is intentionally different from the [reference documentation](../index): the reference is exhaustive and technical, while this guide is narrative and hands-on. If you just want to *get things done*, start here.

**Who should read this** — **users** start with *Using Kwirth*; **administrators** continue with *Administration*; and *Extension manuals* is a per-extension reference (a *user* + *admin* view for each item) for everyone.

The guide has three parts, shown as sections in the sidebar:

- **[Part I · Using Kwirth](user/01-introduction)** — logging in, the UI, selecting resources, channels, workspaces and everyday recipes.
  1. [Introduction](user/01-introduction) · 2. [Accessing Kwirth](user/02-access) · 3. [The Kwirth UI](user/03-ui-tour) · 4. [Selecting what to observe](user/04-selecting-resources) · 5. [Working with channels](user/05-channels) · 6. [Workspaces](user/06-workspaces) · 7. [Everyday tasks](user/07-everyday-tasks)
- **[Part II · Administering Kwirth](admin/01-deployment)** — deployment, security, users, keys, clusters, identity providers and extensions.
  1. [Deployment](admin/01-deployment) · 2. [Initial configuration](admin/02-initial-config) · 3. [User management](admin/03-user-management) · 4. [Security & permissions](admin/04-security-and-permissions) · 5. [API management](admin/05-api-management) · 6. [Cluster management](admin/06-cluster-management) · 7. [Identity Provider integration](admin/07-idp-integration) · 8. [Extending Kwirth](admin/08-extending-kwirth)
- **[Part III · Extension manuals](extensions/index)** — what each plugin, provider, sender, theme, identity provider and homepage does and how to configure it.
