# Sample (provider)

> **Type:** Provider (reference)<br>
> **Package:** `@kwirthmagnify/kwirth-provider-sample`

## What it does

The **Sample** provider is a **reference implementation for provider developers**. It's a minimal, well-commented provider you copy as the starting point for building your own data source — it demonstrates the provider lifecycle and how to distribute events to subscribing channels.

## When to use it

- As a **template** when writing a custom provider.
- To learn the provider API by example.

## Configuration

None for end users — it exists as a **developer scaffold**, not a production data source.

## Notes

- Not meant to run in production; install it only if you're **developing a provider**.
- See the reference [Providers](../../providers/index) section and its developer API for how to build on it.
