# composite

The `composite` sender provides a **visual pipeline editor** in the Kwirth management UI. Instead of writing JSON by hand, you drag-and-drop `tee` nodes (fan-out), `regex` nodes (pattern filtering), and `ref` nodes (reference to a concrete sender config) into a tree that defines the full routing logic for a pipeline.

Under the hood, the pipeline is stored as a JSON tree; at runtime the composite sender interprets that tree and dispatches messages through it node-by-node.

**UI interaction**: When you expand the composite sender card in the Manage Senders dialog, a dedicated **Pipeline Designer** opens instead of the generic config form. There you can:

- Add **tee** nodes to fan a message out to multiple branches.
- Add **regex** nodes with named pattern rules to route or drop based on content.
- Add **ref** nodes that point to a concrete (senderId, configName) pair as a leaf.
- Rename, reorder, and delete any node in the tree.

**No programmatic config is required** — the pipeline is authored entirely from the UI.

Example pipeline JSON (for reference; this is generated by the designer):

```json
{
  "name": "my-pipeline",
  "type": "tee",
  "targets": [
    {
      "type": "regex",
      "rules": [
        { "pattern": "ERROR", "action": "send", "targetId": "branch-errors" }
      ],
      "defaultAction": "drop"
    },
    {
      "type": "ref",
      "senderId": "console",
      "configName": "default"
    }
  ]
}
```
