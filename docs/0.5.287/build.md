# Build Kwirth

This section covers everything you need to build Kwirth from source, for each supported platform and distribution type.

Kwirth can be built and distributed in several forms:

- **Docker image** — the standard Kubernetes deployment artifact.
- **Tauri desktop application** — the recommended desktop experience (Windows, Linux, Mac).
- **Electron desktop application** — alternative desktop build.

Each subsection describes the specific prerequisites and steps for the corresponding build target.
