# Terceros

## Juego

El archivo `src/front/pacman-game.txt` es el juego Pac-Man de **Shaun Williams**
(https://github.com/shaunew/Pac-Man), Copyright © 2012 Shaun Williams,
distribuido bajo licencia GPL v3. El texto completo está en `LICENSE.upstream`
y debe conservarse.

Basado en obras originales de Namco, GCC y Midway. Investigación de Jamey
Pittman y Bart Grantham.

El juego corre dentro de un iframe en el navegador. No se modifica el código
original; se inyecta tal cual en el `srcdoc` del iframe.

## Nombre

"Pac-Man" es marca registrada de Bandai Namco Entertainment. El nombre se usa
aquí de forma descriptiva: no hay arte, sonidos ni ROMs de Namco en el plugin.
El código es una reimplementación en JavaScript, igualmente libre de material
de Namco.

## Resto del plugin

El resto (canal, back, UI, máquina del iframe) es original del plugin para
Kwirth.
