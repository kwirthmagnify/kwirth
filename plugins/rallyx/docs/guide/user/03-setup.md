# Add and configure the channel

## Adding the channel

1. In a Kwirth workspace, click the **ADD** button to add a new tab
2. Select your cluster (or `inCluster` for the local dev cluster)
3. Select view **none** (Rally-X is autonomous — it does not read cluster resources)
4. Select channel **rallyx**
5. Click **ADD**

## Setup dialog

When you click **Start** on the tab, the setup dialog appears:

- **Notify a sender when the record is beaten** — choose a sender (Teams, email, Jira…) to be
  notified when someone beats the #1 high score. Default: *Do not notify*.
- **Pause when the tab loses focus** — if checked, the game pauses when the tab loses focus.
  Default: checked.

Click **OK** to start the game.

## Starting and stopping

- Use the tab's gear menu (⚙) → **Start** to begin
- Use ⚙ → **Stop** to end the session and destroy the game
- Use ⚙ → **Pause** / **Continue** to freeze and resume without destroying the game
