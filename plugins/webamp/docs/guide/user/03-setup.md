# Setup

The Webamp channel setup dialog lets you choose the M3U playlist to load on start.

## Playlist selection

A dropdown lists all available M3U playlists from the [junguler/m3u-radio-music-playlists](https://github.com/junguler/m3u-radio-music-playlists) repository on GitHub. There are 90+ playlists organized by genre and decade:

- **Decades**: 60s, 70s, 80s, 90s
- **Genres**: jazz, blues, rock, electronic, classical, country, dance, metal, pop, soul, funk, reggae, and many more
- **Regional**: french, german, greek, italian, polish, russian, turkish, etc.

The selected playlist is fetched on start and its entries are loaded as initial tracks in the Winamp playlist.

## Default

The default playlist is **80s**. The initial volume is set to 10% and double-size mode is enabled.
