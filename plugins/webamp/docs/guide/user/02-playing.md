# Playing music

## Starting the player

1. Add the Webamp channel to a cluster view
2. Click the tab settings ⚙ → **Start**
3. The Winamp interface appears in the tab with the playlist pre-loaded from the selected M3U

## Adding music

**Drag and drop** is the primary way to load local files:

- Drag audio files (MP3, OGG, WAV, FLAC, M4A, AAC, Opus, WebM) from your file explorer onto the player area
- Drag a `.wsz` skin file to change the Winamp look

**Open songs...** button: opens a Kwirth dialog with the list of radio streams from the M3U playlist. Select a stream to add it to the playlist.

**Load skin...** button: opens a native file picker for `.wsz` skin files.

You can also use **Right-click → Options → Play → Open stream...** for the same stream picker dialog.

## Controls

| Key | Action |
|-----|--------|
| `X` | Play / restart |
| `C` | Pause |
| `V` | Stop |
| `Z` | Previous track |
| `B` | Next track |
| Right-click | Winamp context menu (skins, open files, options) |

## Skins

Winamp classic skins (`.wsz` files) can be loaded by dragging them onto the player. You can find thousands of skins at the [Winamp Skin Museum](https://skins.webamp.org).

## Tab switching

The player survives tab switches: switching to another Kwirth tab and coming back preserves the playlist, the current position, and the skin. The music keeps playing in the background.

To stop the player completely, use the tab settings ⚙ → **Stop**.
