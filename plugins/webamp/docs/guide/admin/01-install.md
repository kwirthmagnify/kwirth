# Installation

## Via the Kwirth marketplace

1. Go to **Settings → Plugins → Marketplace**
2. Find **Webamp**
3. Click **Install**
4. Add the Webamp channel to any cluster view

## Manual installation

If you need to install manually:

1. Download the plugin package (`@iriaoperae/kwirth-plugin-webamp`)
2. Place it in the Kwirth plugins directory
3. Restart Kwirth
