# Troubleshooting

## The player does not appear

- Make sure the channel is **Started** (tab settings ⚙ → Start)
- Check the browser console for errors
- Verify that the browser supports Webamp (modern browsers with Web Audio API)

## Audio files do not load

- Use drag and drop to add files
- Supported formats: MP3, OGG, WAV, FLAC, M4A, AAC, Opus, WebM
- The files are loaded from your local filesystem — they are not uploaded to the server

## Skins do not load

- Skins must be `.wsz` or `.zip` files
- Drag and drop the skin file onto the player area
- Get skins from the [Winamp Skin Museum](https://skins.webamp.org)

## The player disappears when switching tabs

This is expected — the player is hidden when you switch to another tab, but it keeps running in the background. Switch back to the Webamp tab to see it again. The music continues playing.
