# Post Punk — Kwirth Theme

Dark monochrome theme inspired by the post-punk aesthetic: near-black backgrounds, acid-green primary accents, monospace typography.

## Palette

| Token | Dark | Light |
|---|---|---|
| Primary | `#c8e000` (acid green) | `#5a6500` |
| Secondary | `#ff3c78` (hot pink) | `#c0003a` |
| Background | `#0a0a0a` | `#f4f4f0` |
| Paper | `#111111` | `#ffffff` |

## Typography

`IBM Plex Mono` → `Courier New` → `monospace`, 13 px base.

## Install

From Kwirth Settings → Themes → Marketplace, search for **post-punk**.

## Build & Publish

```bash
npm install
node build.mjs
cd dist && npm publish --access public
```
