{{- if include "kwirth.readOnly" . }}

This install cannot change anything in the cluster. Logs, metrics, events and the resource browser work
as always; restart, scale, cordon, drain, evict, apply and delete answer 403, and so does opening a
shell into a pod. The buttons are still in the UI, so do not install the 'ops' and 'fileman' plugins
here. It CAN read Secrets: Kubernetes RBAC has no way to grant everything except one resource.

Metrics need a Kwirth that reads the ServiceAccount token Kubernetes projects into the pod (0.6.65 and
later). On an older image this mode starts fine and says 'There is no SA Token, no metrics will be
available'. The image being installed is {{ include "kwirth.image" . }}.
{{- end }}

The users Secret ('kwirth-users') and the API keys ConfigMap ('kwirth.keys') are kept on uninstall so a
reinstall finds them. Delete them by hand for a clean wipe.
